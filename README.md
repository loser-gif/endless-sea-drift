# 无尽海漂流 / Endless Sea Drift — Web PWA

纯 HTML / CSS / JavaScript + Canvas 2D，无构建工具、第三方依赖、字体或 CDN。上级 Godot 原型保持独立。推荐现代 iOS Safari，横竖屏均可玩。

摇杆 / WASD 移动，E 打捞、G 停靠、B 扩建；长按动作按钮看提示，暂停可静音。Move with joystick / WASD; E collect, G dock, B build. Hold an action for help; mute in pause. Static Canvas PWA, edition XI◇; no build step.

## 本地预览

在此目录运行：

```sh
cd /workspace/endless-sea-drift-play
python3 -m http.server 8000 --bind 0.0.0.0
# 如果系统的 Python 3 命令是 python，也可用 python -m http.server 8000
```

电脑打开 `http://localhost:8000/`；检查：`curl -I http://localhost:8000/`。
同一 Wi-Fi 的手机可打开 `http://电脑局域网IP:8000/` 测试在线玩法。普通局域网 HTTP 不提供 Service Worker；完整离线 PWA 请使用 HTTPS。不要通过 `file://` 打开。

## GitHub Pages

1. 将包含 `web/` 的仓库推送到 GitHub。
2. 在仓库 Settings → Pages 中选择 Deploy from a branch，选择目标分支与 `/ (root)`，保存。
3. 等部署完成后打开 `https://你的用户名.github.io/仓库名/web/`，开启 Enforce HTTPS。若把本目录内容作为独立仓库根目录发布，则打开该站根路径。
4. 所有资源、manifest 的 start_url/scope 与 Service Worker 都是相对路径，可部署于仓库子路径。无需构建。

## iOS 添加到主屏幕与离线

1. 使用 **Safari** 打开已部署的 HTTPS 地址，首次联网加载，等待启动面板显示“离线资源已就绪”。
2. 点击 Safari 的分享按钮 → “添加到主屏幕”，如系统显示“作为 Web App 打开”，保持开启，然后添加。
3. 从桌面图标启动，以 standalone 模式运行；图标使用 180px Apple touch icon，manifest 另提供 192px / 512px PNG。
4. 启动成功后，关闭应用、开启飞行模式，再从桌面启动验证离线壳。系统可能回收网站缓存，回收后需重新联网。

已配置 viewport-fit=cover、刘海安全区、apple-mobile-web-app-capable、theme-color、任意方向与动态视口高度。touch-action:none、overscroll-behavior:none 与手势事件处理减少缩放、滚动干扰；系统边缘导航仍由 iOS 控制。

## 玩法与数值

- 起步 3×3 木筏；木材 12、布料 5、食物 3、淡水 3。
- 木板 100 耐久；相邻边缘扩建每格 2 木材，最多 81 格。仅与中央炮台连通的板块保留；中央损毁则木筏覆灭。
- 打捞半径 115；木材每份 +2，其余 +1。物资按木 / 水 / 木 / 食 / 布循环漂来，每 1.9 秒一份。
- 饱腹每秒 −0.40、水分每秒 −0.58（暴雨 ×1.25，雨棚可减缓）；食物 +32、水 +38（上限 100）。任一归零结束。
- 自动炮射程 265；装弹伤害 38、间隔 0.48 秒，无弹弱射伤害 22、间隔 0.95 秒。额外炮台各消耗一发；混合齐射若有装弹炮则采用快射间隔。击杀掉食物。
- 首怪在 8 秒后生成；后续间隔从约 11 秒渐降至 4 秒。全筏修补每格 +45 耐久，消耗 1 木材和 1 布料。
- 每约 5 秒、暂停、切后台及离开页面自动保存到 localStorage；重开可继续。结束存档不可续玩，重新启航开始新局。

## 文件与缓存维护

`index.html` 是界面，`styles.css` 是响应式触控布局，`game.js` 是游戏主循环，`art.js` 缓存海浪材质、增强精灵并合成高光；`manifest.webmanifest` 和 `sw.js` 提供安装元数据与离线壳。`icons/` 为程序生成的像素木筏 PNG。

`sw.js` 安装时预缓存首页、脚本、样式、manifest 和图标；导航联网优先，离线返回缓存首页；核心资源缓存优先。更新发布时递增 `CACHE` 名称中的版本号，确保新资源重新缓存，关闭旧标签后重新打开以使用完整新版本。缓存清理仅针对本游戏前缀。

建议真机验收：横竖屏启航 → 多指移动并打捞 → 扩建 → 吃喝与修补 → 暂停/后台恢复 → 结束并重启 → 添加到主屏幕 → 飞行模式冷启动。自动化逻辑检查和 HTTP 200 不能代替 iPhone 真机安装与手势验证。

## 画质 v4 · HD

保持纯静态 Canvas 2D PWA，无 WebGL、第三方库、CDN 或运行时网络素材，玩法、碰撞、资源数值和输入逻辑沿用 v3。

- **海水**：远景薄雾、中景弧形波谷、近景交错焦散与破碎日光反射。4 组预烘焙波纹和焦散，以不同尺寸、速度与透明度组成纵深；弱化 v3 的直线光束。
- **木筏**：4 种木板变体，添加木节、长短木纹、钉头、深接缝、侧面厚度 AO 与冷色湿边反射；外沿根据邻格绘制。
- **实体**：角色面部、衣物接缝、炮管金属高光、物资冷色暗面与海怪鳞片 rim。海怪尾部独立摆动、身体轻微起伏，只影响绘制。
- **后处理**：只将日光高光与射击落点写入 1/10 宽高的离屏辉光层，使用缓存径向光斑；柔暗角，极轻的冷暖错位仅限水面高光。无全屏像素读回、实时 blur 或整幅画面色差。
- **像素与 HUD**：世界以 2.5 倍 nearest 放大（v3 为 3 倍），保留像素边缘但增加细节；HUD 收敛边框、阴影与金色按钮，增加小型 IV 版本标。三个 PNG 图标以同套 v4 木纹重绘，加入罗盘闪光。

`game.js` 中 `quality` 为 `{pixel: 2.5, fps: 30}`。海浪固定 110 组、反射 56 条；海浪/焦散/精灵在启动时生成，背景与暗角以世界画布分辨率缓存，仅 resize 时重建。辉光缓冲约为 CSS 屏幕面积的 1%，独立平滑放大后合成，主体仍为 nearest。逻辑仍逐 RAF 更新，绘制限 30fps，HUD 约 10Hz。系统“减少动态效果”会停止装饰波动、漂浮与摆尾。

SW 缓存为 `endless-sea-drift-v4-hd`，预缓存包含新增 `art.js`。`_shot-v4.png` 是 Playwright 实际运行截图，仅供预览，不加入离线缓存。

目标仍为 iOS Safari 约 30fps。桌面 Chromium 的手机尺寸模拟用于布局、离线及性能回归，不能代替 iPhone 真机 GPU、温升、触控和安装验收。

## 画质 v5 · Cinema

保持纯静态 Canvas 2D PWA，玩法、触控、碰撞、资源数值均不变。相对 v4：

- **海水**：新增 4 张预烘焙宽涌浪材质，15 层双段水流以不同速度和尺度叠加；亮肩、深波谷、渐隐接缝形成体积。提高交错焦散亮度，扩展暖金反射带；远景增加三层薄雾。
- **木筏**：提高木纹、木节和板缝对比，外侧受光边更亮、背光侧 AO 更深；下沿增加青绿色湿边、水线反光与少量周期泡沫、飞沫。仅外沿绘制，每格固定数量，无粒子池增长。
- **光影**：左上黄金时段暖光增强，水面暗部保持深蓝；木筏、实体的亮边与冷暗面拉开对比，炮台增加接触阴影和炮管投影。
- **后处理**：仍使用 1/10 宽高高光缓冲，增加双次 screen 合成的 bloom，强化缓存暗角；无逐像素色调映射、全屏读回或实时 blur。
- **微动画**：漂浮物轻微侧摆与呼吸水圈；海怪增加鳍摆、身体呼吸和眨眼；炮管轻微伺服摆动及射击后坐。系统“减少动态效果”下停止这些装饰动画。
- **PWA 与图标**：版本徽标 V；三个图标沿用原有构图，更新高对比木板、暖光水面和弧形水流。SW `CACHE = endless-sea-drift-v5-cinema`，`SHELL` 含 `art.js`。

性能预算维持 `quality = {pixel: 2.5, fps: 30}`，逻辑逐 RAF 更新、HUD 约 10Hz；宽涌浪、焦散、精灵、雾和暗角都提前缓存。新增每帧 30 次宽水流贴图，bloom 缓冲约为 CSS 屏幕面积的 1%；无需 WebGL、CDN、打包器或网络素材。
